# Real-Time Electric Vehicle Dashboard & ADAS Warning System

Developed an Electric Vehicle (EV) Dashboard and ADAS Warning System using STM32F103C8T6, STM32CubeIDE, PICSimLab, and Python. The project implements EV control features such as speed, torque, battery SOC, range estimation, regenerative braking, motor temperature monitoring, and HC-SR04-based obstacle detection. It also includes fault management and a real-time dashboard for visualizing vehicle telemetry.
