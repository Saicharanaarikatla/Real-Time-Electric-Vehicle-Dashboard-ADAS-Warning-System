# Real-Time-Electric-Vehicle-Dashboard-ADAS-Warning-System
Developed an EV ADAS using STM32F103C8T6, STM32CubeIDE, PICSimLab, and Python. Implemented EV control (speed, torque, SOC, range), HC-SR04-based obstacle detection, fault management, and a real-time Python dashboard. Used C, STM32 HAL, UART, ADC, PWM, timers, and interrupts for embedded system integration.
